# ☕ Java Journey: From Zero to Spring Boot

Welcome to my study repository! This is where I document my daily learning and progress in **Java**, moving from basic programming logic to building robust APIs with **Spring Boot**.

## 🎯 Goal
The purpose of this repository is to track my growth, store coding exercises, log challenges, and consolidate practical projects to build a strong foundation as a Java developer.

## 🗺️ The Journey Roadmap

- [x] **Java Fundamentals:** Syntax, variables, operators, conditional statements, and loops.
- [ ] **Object-Oriented Programming (OOP):** Classes, objects, inheritance, polymorphism, encapsulation, and abstraction.
- [ ] **Data Structures & Collections:** Lists, Sets, Maps, and Array manipulation.
- [ ] **Exception Handling & File I/O:** Try-catch blocks, custom exceptions, and reading/writing files.
- [ ] **Advanced Java:** Lambdas, Streams API, Generics, and Concurrency.
- [ ] **Database & JDBC:** Connecting to relational databases (MySQL/PostgreSQL) and SQL queries.
- [ ] **Spring Ecosystem:** Spring Boot, Spring Data JPA, Spring Security, and building RESTful APIs.

## 🛠️ Tech Stack & Tools
- **Language:** Java (Version 17+)
- **IDE:** IntelliJ IDEA / Eclipse
- **Dependency Management:** Maven / Gradle
- **Databases:** H2, MySQL, PostgreSQL
- **Main Framework:** Spring Boot
